# ES-module shell

Read the root [instructions](../AGENTS.md), [host instructions](../src-tauri/AGENTS.md) and [shell contract](../docs/ui-shell.md) before editing. This is the restart's authored source, served directly by Tauri with no framework, bundler, npm runtime dependency or third-party script. Preserve `dist/` and its running host until the separately owned cutover.

[manifest.js](manifest.js) is metadata only; [widget-loaders.js](widget-loaders.js) is the closed first-party executable registry. A JSON definition never supplies a module path, stylesheet, HTML, bridge method or executable handler. The palette is built from metadata even for off widgets. Each entry names its panel, settings and commands. Add a port by replacing its loader, with the native capability reviewed in its own issue; a placeholder is visibly unavailable and is not a port.

[lifecycle.js](lifecycle.js) owns the surface, stylesheet, AbortSignal and asynchronous cleanup for each widget. Import only a selected enabled widget; keep other enabled surfaces alive when switching views. Off aborts immediately, detaches its DOM and CSS and waits for teardown before a new lifetime starts. Every mounted widget must release its own listeners, timers, subscriptions and native resources through `dispose`; every delayed operation checks its lifetime before updating the page. JavaScript modules remain cached after off; browsers have no unload operation.

[preferences.js](preferences.js) uses the core's typed settings/widget commands. Do not fall back to prototype localStorage or clear unreadable data. On/off are the only UI states; active/inactive are wire translations for the existing core. The [JSON contract](definitions.js) is an ES-module port pinned to the legacy pure validator by [the parity check](../scripts/check-ui-declarative.mjs). Change both validators and the schema together when deliberately extending that contract.

[tokens.css](tokens.css) holds every colour, size, radius and duration, dark first with a light theme for a system set to light, and the shared control rules; [shell.css](shell.css) and the widget stylesheets name no colour, duration or size above 3 px of their own, and every token is used ([check-ui-rail.mjs](../scripts/check-ui-rail.mjs) holds both), and one rule in the tokens turns all motion off for a person who asked for less. The page is the companion rail's contents ([rail contract](../docs/companion-rail.md)): [rail.js](rail.js) follows the host's `rail.status` and `rail.changed` and asks for changes with `rail.set`, and never decides the window's state itself. The layout follows the window's own width, so the strip alone is drawn at the strip's width and nothing waits for a message; keep the strip's buttons where they are when the panel opens around them. Views are drawn for one narrow column of about 344 px and must also read well wide; a view that needs room is listed in `wideViews` in the manifest. Commands and Settings open as sheets over the view inside the panel, and the view under them stays mounted. [attention.js](attention.js) is what the closed strip says about a view: a view sets its own mark through `context.attention`, and marks are cleared when the person opens the view. Where the host reports the ordinary window, or there is no host, the same page is the whole panel all the time.

[context-menu.js](context-menu.js) is the only context menu: the web view's native one is never opened ([host instructions](../src-tauri/AGENTS.md) say why), so do not stop a `contextmenu` event to bring it back, and give a part of the page its own items with `provideMenu`. The menu is the shell's and is mounted once; a widget's provider is kept by its element and goes with it. While the menu has the keyboard no key goes on to the page; when the page itself puts the keyboard somewhere else the menu closes and leaves it there; Cut and Paste leave alone a field that changed or was taken out of the page while the clipboard answered, so a view may draw its fields again under an open menu; and a scroll closes it only when what scrolled holds the part of the page the menu belongs to: a terminal that prints beside it does not.

[widgets/shells.js](widgets/shells.js) owns terminal tabs and [their styles](widgets/shells.css); [terminal.js](terminal.js) retains pacing, acknowledgements and close semantics. The emulator's one reviewed vendor global is consumed by this widget alone; no widget writes a shared application global. Never shadow the two vendored emulator assets in this folder.

[widgets/today.js](widgets/today.js), [widgets/projects.js](widgets/projects.js) and [widgets/focus.js](widgets/focus.js) are the default views ([contract](../docs/default-views.md)). They write items only through [items.js](items.js) and the focus session only through [focus-model.js](focus-model.js), create their stores per lifetime, and read again when shown; keep every draft in its field until the core has answered. Change the archive rule, caps, capture fields, calculator or world clock only together with their parity checks.

Run `node scripts/check-ui-rail.mjs`, `node scripts/check-ui-items.mjs`, `node scripts/check-ui-focus.mjs`, `node scripts/check-ui-palette-answers.mjs`, `node scripts/check-ui-shell.mjs`, `node scripts/check-ui-declarative.mjs`, `node scripts/check-tauri-terminal.mjs`, `node scripts/check-tauri-summon.mjs` (it runs the context menu) and `node scripts/check-tauri-bridge.mjs`, then the rendered checks in the shell contract, the [views browser fixture](../scripts/fixtures/ui-views-browser.mjs) and full Mac verification. Headless models, browser fixtures, native renderer fixtures, a launched Tauri app and installed/device acceptance are separate evidence classes. Keep startup resource traces, original failures and exact source identity in common Git receipts.
