# ES-module shell

Read the root [instructions](../AGENTS.md), [host instructions](../src-tauri/AGENTS.md) and [shell contract](../docs/ui-shell.md) before editing. This is the restart's authored source, served directly by Tauri with no framework, bundler, npm runtime dependency or third-party script. Preserve `dist/` and its running host until the separately owned cutover.

[manifest.js](manifest.js) is metadata only; [widget-loaders.js](widget-loaders.js) is the closed first-party executable registry. A JSON definition never supplies a module path, stylesheet, HTML, bridge method or executable handler. The palette is built from metadata even for off widgets. Each entry names its panel, settings and commands. Add a port by replacing its loader, with the native capability reviewed in its own issue; a placeholder is visibly unavailable and is not a port.

[lifecycle.js](lifecycle.js) owns the surface, stylesheet, AbortSignal and asynchronous cleanup for each widget. Import only a selected enabled widget; keep other enabled surfaces alive when switching views. Off aborts immediately, detaches its DOM and CSS and waits for teardown before a new lifetime starts. Every mounted widget must release its own listeners, timers, subscriptions and native resources through `dispose`; every delayed operation checks its lifetime before updating the page. JavaScript modules remain cached after off; browsers have no unload operation.

[preferences.js](preferences.js) uses the core's typed settings/widget commands. Do not fall back to prototype localStorage or clear unreadable data. On/off are the only UI states; active/inactive are wire translations for the existing core. The [JSON contract](definitions.js) is an ES-module port pinned to the legacy pure validator by [the parity check](../scripts/check-ui-declarative.mjs). Change both validators and the schema together when deliberately extending that contract.

[context-menu.js](context-menu.js) is the only context menu: the web view's native one is never opened ([host instructions](../src-tauri/AGENTS.md) say why), so do not stop a `contextmenu` event to bring it back, and give a part of the page its own items with `provideMenu`. The menu is the shell's and is mounted once; a widget's provider is kept by its element and goes with it. While the menu has the keyboard no key goes on to the page, and a scroll closes it only when what scrolled holds the part of the page the menu belongs to: a terminal that prints beside it does not.

[widgets/shells.js](widgets/shells.js) owns terminal tabs and [their styles](widgets/shells.css); [terminal.js](terminal.js) retains pacing, acknowledgements and close semantics. The emulator's one reviewed vendor global is consumed by this widget alone; no widget writes a shared application global. Never shadow the two vendored emulator assets in this folder.

Run `node scripts/check-ui-shell.mjs`, `node scripts/check-ui-declarative.mjs`, `node scripts/check-tauri-terminal.mjs`, `node scripts/check-tauri-summon.mjs` (it runs the context menu) and `node scripts/check-tauri-bridge.mjs`, then the rendered checks in the shell contract and full Mac verification. Headless models, browser fixtures, native renderer fixtures, a launched Tauri app and installed/device acceptance are separate evidence classes. Keep startup resource traces, original failures and exact source identity in common Git receipts.
