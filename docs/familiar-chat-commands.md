# Persistent familiar chat

Familiars keeps one application conversation per familiar. Reopening, reconnecting and restarting the app retain its conversation identity, messages, drafts and provider continuation. New chat, reset actions and the former `coven.new` route are removed. Existing conversation heads and earlier archive files are preserved. The active head is bounded to 120 recent messages and 512 KiB of text; older turns are written atomically to private history segments under the same conversation identity before being removed from the active context. These segments remain on this Mac rather than being sent automatically to a provider.

Every reply includes a host-generated Open Sesame application-context preamble containing the familiar and application conversation IDs. New Coven records request the title `Open Sesame · <familiar>` and label `open-sesame`; the CLI retains existing ledger metadata when continuing an older record. The renderer cannot supply a different origin, workspace, permission or arbitrary CLI arguments. This is application context, not a cryptographic provider-attestation claim. Existing read-only policy and session/workspace checks remain enforced; changing a workspace or session binding fails closed while keeping the conversation.

Type `/` or choose the slash button beside the composer to open commands. Arrow keys choose an entry, Enter runs it, and Escape dismisses the menu without submitting a message. `/find <text>` searches the transcript; `/copy` copies its visible saved messages, `/stop` stops the current app-owned reply, `/refresh` reconnects without resetting, and `/help` lists commands. Drafts and commands remain available while a reply streams. Start with `//` to send a literal leading slash. Unknown commands and removed reset commands never become model prompts.

`/coven` and `/coven help` list the available Coven operations. `/coven status`, `/coven sessions`, `/coven familiars` and `/coven skills` run fixed, supported metadata commands through the installed CLI. Sessions are filtered to the chosen familiar and workspace. Output is projected onto bounded display fields, escaped and rendered locally; it is not appended to the conversation or forwarded as model context. No arbitrary command, argument, shell execution, provider credential or configuration payload is exposed by this route. Coven Code's interactive-only commands are not advertised as chat capabilities.

The installed CLI help was checked for `run`, `status`, `sessions`, `familiars` and `skills`. The usage-only inner-result behavior was verified in Coven Code's `src-rust/crates/cli/src/main.rs`; Coven's `crates/coven-cli/src/pty_runner.rs` normalizes native frame session IDs before its authoritative completion. The app now ignores the known usage-only inner result and still requires the exact policy-bound outer completion. Missing outer completion, foreign IDs, malformed error flags and provider failures remain failures; captured text is kept.

The healthy connection row is removed from the layout. Refresh stays in the roster heading, and connection errors/setup guidance remain available when needed. Chat has a quieter header, a fitted expanding composer, an accessible command list and local result panel. Native avatar updates also pass through the existing authenticated allowlist, correcting an omitted route without widening renderer authority.

Run `npm run verify` with `OPEN_SESAME_VERSION=0.0.13`. Fixture checks cover persistent identity, application origin on continued replies, private history segments, real JS-to-Python command routing, no model calls from local commands, keyboard behavior, draft preservation, late command results and legacy completion handling. A CLI probe using `coven code help` was interpreted as a prompt by the installed engine; subsequent discovery used command-specific `--help` and source. That probe is separate from the synthetic verification and did not send a message to a familiar. Actual provider continuation/awareness and rendered/native acceptance must be reported separately from fixture and build evidence.
