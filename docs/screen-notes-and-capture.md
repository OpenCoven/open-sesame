# Screen notes and capture feedback

Open Screen notes with `/screenshot` or the screen icon beside the attached-link field. Opening the review does not capture anything. In the Mac app, Capture screen opens a native confirmation with a display choice, Cancel as the default keyboard action, and a description of the capture. The screenshot excludes Open Sesame, contains no audio, and runs only after Capture screen is confirmed. macOS Screen Recording permission is required. Screen capture uses [ScreenCaptureKit’s screenshot API](https://developer.apple.com/documentation/screencapturekit/scscreenshotmanager) on macOS 14 or later; earlier supported Macs can choose an existing screenshot instead.

Choose screenshot opens the native image picker. Images are bounded by file size and decoded pixel dimensions, resized before processing, and read with local [Vision text recognition](https://developer.apple.com/documentation/vision/recognizing-text-in-images). The review contains an image preview, editable title, extracted text and any supplied context. This is text extraction, not a claimed AI description of the image. Nothing is automatically sent to Coven, another model or a remote OCR service. Save note stores the reviewed text in the project selected when the review opened; the image stays in memory. In the browser, choose an image and write notes manually; local macOS OCR is unavailable there.

Replacing an existing capture or edited draft asks inside the review before discarding its contents. Cancelled pickers, denied capture, late replies, closing the review, unavailable projects and storage failures preserve the draft. Closing cancels any outstanding native acquisition and ignores late results. Sign-out and app termination cancel native capture work. There is no background capture or continuous screen stream.

The closed notch prioritizes an active audio session over media controls. Microphone, system audio and their combined source have distinct icons; transcription shows input-level bars, recording shows REC with the same measured-level bars, and starting/finishing are labeled explicitly. Microphone speech now emits level events as well as recognized text. Playing media shows a transport animation, not a claim to measure the media’s waveform; it stops when playback stops and respects reduced-motion settings. These indicators do not request additional microphone, screen or system-audio access.

System-audio output now follows the monotonic capture clock rather than counting timer callbacks. A short jitter buffer, bounded catch-up and stop-time drain keep delayed/coalesced dispatch callbacks from causing permanent silence or dropping the buffered tail. A recording is offered as ready only after actual source input arrives, rather than merely after generated silence reaches the encoder. Timing, source mixing and PCM conversion are exercised with synthetic buffers; hardware permission, actual sound, the speech provider and saved real recordings remain separate acceptance checks.

The shared HTML select listbox is treated as an inside interaction even when it is mounted outside the widget container. Native app-owned window and popup events are also excluded from outside-click dismissal, including tracking during a dropdown selection. True outside events still collapse an unpinned widget. The Mac companion source-download button is hidden in the installed app and retained for browser users.

Familiars keep the existing shared rail, collapse preference, persistent conversation and keyboard tab behavior. Their identity rows are enlarged to 62 px with 40 px avatars, a wider responsive rail, more generous spacing, an inset selected treatment and refined hover/press/focus states. Narrow panes scale the rows and avatars while retaining independent list scrolling. Only replying rows reveal their progress subtitle, keeping idle rows quiet.

Local source/transport tests, actual synthetic-image Vision OCR, native compilation, Safari WebKit fixture rendering, hosted verification, private packaging, installed UI, actual device capture and provider execution are distinct evidence classes. Do not use a synthetic bridge or a compiled bundle as proof of real system audio or screen-capture acceptance. An embedded Coven computer-use agent is outside these Screen notes capabilities and requires its own current claim and end-to-end evidence.
