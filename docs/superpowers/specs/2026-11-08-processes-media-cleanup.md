# Processes and media cleanup

The user approved compact process rows, one filter bar, secondary process actions under a menu, one media playback bar, one file-selection button, and a drop hint only when empty or dragging. Preserve existing functionality, task/process safety, playback state and user data. Use the existing plain JavaScript/CSS application and shared controls.

An all-native media player would retain duplicate app controls or require removing shared playlist transport; an app-owned transport gives one consistent bar for audio and video. Keep native controls as a fullscreen fallback. For Processes, keep all five layouts behind one layout selector; move less frequent filters and history clearing into a disclosure. Keep terminal navigation direct and process signals behind the existing confirmation semantics.

Existing worktrees, installed application and shared owner claims are preserved; other agent/process candidates remain independently owned. Browser fixture evidence and native installed acceptance remain distinct.
