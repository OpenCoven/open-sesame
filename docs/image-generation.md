# Image Studio

Install Image Studio in Widgets, then choose Open in Media. Connect ChatGPT opens the existing Codex login flow in the account terminal. Complete the provider's browser sign-in and choose Refresh connection. This uses the official installed Codex CLI and its ChatGPT account; no API key, copied token, custom endpoint or API fallback is accepted.

Describe an image, choose square, landscape or portrait, and press Generate image. Only that explicit action submits the prompt. Opening, installing, refreshing the connection and restoring a draft never generate an image. Built-in image generation uses the service/model supplied by Codex; the widget does not promise an API model version or expose an unsupported model selector. Account plan, workspace policy, image availability and usage limits still apply. See [OpenAI's image-generation guide](https://learn.chatgpt.com/docs/image-generation).

The completed PNG appears in the preview. Save PNG opens the native file picker and writes a validated, re-encoded PNG to the location you choose. Prompts and shape are saved locally; preview pixels are held in the current window rather than stored in localStorage or workspace handoff. Save the image before closing or moving to a different app window. Codex also retains its original under its own generated-images directory; uninstalling this widget does not delete it or exported files.

Stop, deactivation, leaving the page, collapse, document hiding and shutdown retire the pending response and stop the owned CLI process. Stopping does not guarantee that already started provider work is uncounted. A cancelled or failed request is never retried automatically. Failed generation retains the prompt and any earlier completed preview. Account identity is checked before and after generation; changed sign-in invalidates the result.

The host uses an ephemeral CLI session with a deny-by-default filesystem profile that permits reads only in its temporary request directory, with user configuration, project instructions, hooks, shell, browser, web, MCP, plugins, skills, computer controls and delegation disabled. Only built-in image generation is enabled. The output must come from the exact CLI thread's generated-images directory; arbitrary paths, symlinks, non-PNGs and oversized previews are rejected. Credentials stay with Codex. Login status establishes account configuration, not successful generation or quota availability. Provider diagnostics and private paths are not shown as errors.

Browser previews show the widget and preserve drafts, but generation and native export require the authenticated Mac app. Tests use isolated CLI fixtures, delayed bridge responses and native PNG fixtures; they do not establish provider or installed-device acceptance. Actual live and rendered qualification receipts belong in the common Git task record.
