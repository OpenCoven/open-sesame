# Local speaker labels

Live retains its plain transcript and adds an optional Speakers control. Choose Set up speakers to open a setup command in embedded Shells; this installs a separate Python 3.12/3.13 NeMo runtime and downloads the pinned 471 MB NVIDIA Sortformer v2.1 checkpoint. Enable Speakers before Start. Setup never starts capture or sends a model prompt. The normal transcript path does not require NeMo.

The model runs locally on CPU, with at most four anonymous speaker slots and support for overlapping speech. Its intervals are aligned to native speech-recognition word timestamps. Speaker 1, Speaker 2 and subsequent names are assigned by first observed appearance; they are estimates, not identified people. Use Speaker names to add names yourself. Unattributed text stays Unknown speaker, and text beyond the processed audio remains Identifying speaker while processing continues. Plain text stays available, and copy, note saving, transcript export and transcript questions can include speaker labels.

Speaker mode temporarily buffers captured audio in a private, session-owned local directory. The sidecar has one inference in flight and coalesces updates under CPU load, retaining the full arrival-order audio context rather than independently renaming voices in unrelated chunks. The latest processed timestamp is shown. Audio is deleted when the sidecar ends or is cancelled; speaker labeling does not upload audio. Speech recognition retains the platform’s existing on-device/network behavior. Turning speaker labels off preserves the original text-only capture behavior. Names and labels belong to the current capture; previous transcript text is retained when another capture starts.

Stop ends input first and updates the interface immediately. Recognition gets a bounded grace period to finalize its last words; Finish now keeps the text already captured without waiting for that tail. Speaker inference finishes separately and cannot keep the microphone listening. Starting another capture cancels the previous labeling worker. Sign-out and app shutdown cancel owned workers, and shutdown removes their temporary audio. Check provider setup in Familiars is separate from local speaker-model setup.

The implementation uses [NeMo speaker diarization concepts](https://docs.nvidia.com/nemo-framework/user-guide/latest/nemotoolkit/asr/speaker_diarization/intro.html) and the [Sortformer v2.1 model](https://huggingface.co/nvidia/diar_streaming_sortformer_4spk-v2.1). The model revision is `cd03eee90fbec18297ac31b8c21546e596b7f71c`; its SHA-256 is `8abd32832159c6ac1148c926b7276f35ba34582c444e559dce1f1253fea42ef8`. Weights remain external to the application bundle under NVIDIA’s linked model license. The managed runtime pins NeMo `3.0.0` and its [tested dependency versions](../desktop/diarization-constraints.txt) and disables model downloads during inference.

[Speaker alignment checks](../scripts/check-speaker-model.mjs), [Python interval checks](../desktop/tests/test_diarization.py), [native sidecar tests](../desktop/tests/SpeakerDiarizationTests.swift), [retained word timing tests](../desktop/tests/SpeechTranscriptTests.swift) and the [workspace recovery browser review](../scripts/review-workspace-recovery.mjs) cover synthetic boundaries. A local real-model probe used generated multi-voice speech and detected two distinct voices with the repeated first voice retaining its slot. That establishes model execution, not meeting-quality diarization accuracy, real microphone permissions or installed-app acceptance.
