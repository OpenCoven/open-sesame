# Native host and Python adapters

Read the [repository map](../docs/repository-map.md), [desktop setup](README.md) and [capability boundaries](../docs/capabilities.md). [OpenSesame.swift](OpenSesame.swift) owns AppKit/WKWebView lifecycle and method routing; [bridge.py](bridge.py) owns the stdio JSON service and real PTY sessions. Swift-only capture/window/account and [VNC transport](VNCTransport.swift) handlers and Python-backed operations are separate paths.

Keep authentication, trusted main-frame file-origin validation and per-method validation at the receiving boundary. External WKWebViews cannot inherit the application message handler. Full-access Familiar replies use [native request-bound confirmation](FamiliarPermissions.swift) and backend policy binding. A renderer flag or executable discovery is not authorization. Sign-out/expiry must close the relevant host work; retain cancellation, generation checks and identity-bound process cleanup.

For a bridge feature, inspect its caller in [dist](../dist/), Swift routing, Python dispatch and adapter, then add the corresponding [tests](tests/). If adding a native Swift file or bundled Python module, update [build-macos.sh](build-macos.sh) and its focused native check where required. Keep stdout in the bridge machine-readable and diagnostics free of credentials/private payloads. Treat real PTY startup, resize, bytes and cleanup assertions as behavioral contracts.

Use temporary fixture state for Familiar/GitHub tests. Persistent conversations and settings are user data, not disposable test artifacts. The installed bundle identifier preserves native website data and permissions. Do not reset Keychain, browser storage, saved conversations, avatars or permissions to work around an environment blocker. Mac account/GUI, actual audio/screen permissions, live OAuth and provider turns remain separate acceptance.

Run `npm run verify` from the root for native qualification. [check-native.sh](../scripts/check-native.sh), [check-authentication.sh](../scripts/check-authentication.sh) and [check-screen-notes.sh](../scripts/check-screen-notes.sh) compile/run synthetic Swift tests. [Desktop Python tests](tests/) exercise real local PTYs plus deterministic provider/network fixtures. Build-only with `bash desktop/build-macos.sh`; `npm run dev:macos` also launches the app. Both use the existing Python selection and pinned offline SDK. Never replace or quit an installed app with active user work as a side effect of source verification.

[SpotifyAuthentication.swift](SpotifyAuthentication.swift) owns native Spotify tokens and fixed-endpoint read-only library requests. The `music.spotify.library` route accepts only a validated kind and numeric offset; return normalized song/playlist metadata and recheck the account epoch after awaiting the provider. Never accept renderer-supplied provider URLs or return tokens.

[SpeechTranscript.swift](SpeechTranscript.swift) retains utterances across native speech-result resets using audio timestamps and completed-utterance boundaries. Corrections replace their matching audio span; empty callbacks preserve captured text. [Synthetic retention tests](tests/SpeechTranscriptTests.swift) run in the native checks without microphone access. Keep capture identity checks and on-device recognition policy intact.

[image_generation.py](image_generation.py) invokes only the official Codex built-in image tool with ChatGPT sign-in. Preserve disabled shell/browser/MCP/plugin/skill controls, exact-thread output containment, account identity checks and bounded owned-process cleanup. [ImageExport.swift](ImageExport.swift) validates and re-encodes bounded PNGs before the native save picker; no renderer path or provider credential is accepted.

[TerminalClipboard.swift](TerminalClipboard.swift) handles explicit terminal clipboard actions behind the existing authenticated main-frame file-origin guard. It accepts plain text only, validates exact request fields and a 1 MiB UTF-8 limit, and never reads clipboard content in the background. Tests use a private pasteboard, preserving the user clipboard. Renderer paste completion must stay bound to the same visible, live shell; keep xterm bracketed-paste handling and ordinary Ctrl-C interrupts.

[SpeakerDiarization.swift](SpeakerDiarization.swift) owns the opt-in local NeMo sidecar, fixed managed runtime/model paths, strict session IDs, PCM conversion and private temporary audio cleanup. [diarization_worker.py](diarization_worker.py) loads the pinned verified model without runtime downloads and emits bounded anonymous intervals. Model setup runs only from an explicit embedded-shell action; capture never installs dependencies. Keep Stop/cancel, sign-out, process exit and owned-file cleanup independent of inference. [Native sidecar tests](tests/SpeakerDiarizationTests.swift) use a disposable Python protocol fixture; real NeMo inference and live microphone/diarization quality are separate evidence.

Media pop-outs use isolated WKWebViews, never the application bridge. [LocalMediaPlayers.swift](LocalMediaPlayers.swift) accepts bounded ordered file chunks into owned temporary directories and loads only the trusted player template with that directory as its read scope; retain upload limits and close/sign-out cleanup. Preserve generations when a YouTube view is reparented or retired into an independent window; only validated Spotify/Apple embed URLs may create other player windows. Protected Share fullscreen/resize must preserve explicit self-exclusion and first-complete-frame readiness.

[TranscriptExport.swift](TranscriptExport.swift) validates exact UTF-8 transcript save requests with a 4 MiB limit. Export uses the authenticated main-frame bridge and native save sheet rather than blob navigation, which the host rejects. Preserve cancellation, duplicate-save guards and authentication checks before writing; never accept a renderer-selected filesystem path.

[WindowSizing.swift](WindowSizing.swift) clears native aspect constraints using positive content resize increments. Do not assign a zero aspect ratio to remove a constraint: AppKit can install zero frame increments and produce NaN frames during live resizing or display moves. Preserve actual native resize and display-move acceptance separately from geometry fixtures.
