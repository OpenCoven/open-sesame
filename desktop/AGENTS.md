# Native host and Python adapters

Read the [repository map](../docs/repository-map.md), [desktop setup](README.md) and [capability boundaries](../docs/capabilities.md). [OpenSesame.swift](OpenSesame.swift) owns AppKit/WKWebView lifecycle and method routing; [bridge.py](bridge.py) owns the stdio JSON service and real PTY sessions. Swift-only capture/window/account and [VNC transport](VNCTransport.swift) handlers and Python-backed operations are separate paths.

Keep authentication, trusted main-frame file-origin validation and per-method validation at the receiving boundary. External WKWebViews cannot inherit the application message handler. Full-access Familiar replies use [native request-bound confirmation](FamiliarPermissions.swift) and backend policy binding. A renderer flag or executable discovery is not authorization. Sign-out/expiry must close the relevant host work; retain cancellation, generation checks and identity-bound process cleanup.

For a bridge feature, inspect its caller in [dist](../dist/), Swift routing, Python dispatch and adapter, then add the corresponding [tests](tests/). If adding a native Swift file or bundled Python module, update [build-macos.sh](build-macos.sh) and its focused native check where required. Keep stdout in the bridge machine-readable and diagnostics free of credentials/private payloads. Treat real PTY startup, resize, bytes and cleanup assertions as behavioral contracts.

Use temporary fixture state for Familiar/GitHub tests. Persistent conversations and settings are user data, not disposable test artifacts. The installed bundle identifier preserves native website data and permissions. Do not reset Keychain, browser storage, saved conversations, avatars or permissions to work around an environment blocker. Mac account/GUI, actual audio/screen permissions, live OAuth and provider turns remain separate acceptance.

Run `npm run verify` from the root for native qualification. [check-native.sh](../scripts/check-native.sh), [check-authentication.sh](../scripts/check-authentication.sh) and [check-screen-notes.sh](../scripts/check-screen-notes.sh) compile/run synthetic Swift tests. [Desktop Python tests](tests/) exercise real local PTYs plus deterministic provider/network fixtures. Build-only with `bash desktop/build-macos.sh`; `npm run dev:macos` also launches the app. Both use the existing Python selection and pinned offline SDK. Never replace or quit an installed app with active user work as a side effect of source verification.
